# 翻翻卡 · FlipMemories

翻翻卡是一款 macOS 纪念册编辑器。你可以整理照片、文字和语音，备份相册，也可以把纪念册导出成礼物。

下载 [翻翻卡 v0.2.0](https://raw.githubusercontent.com/Tohsaka-Rin-Ovo/flip-cards/main/downloads/v0.2.0/FlipMemories-v0.2.0.zip)。支持 macOS 14 或更新版本、Apple 芯片和 Intel。

解压后，将「翻翻卡.app」拖到「应用程序」。此版本未获 Apple 公证。如果系统拦截，请先确认下载来源，再到「系统设置 → 隐私与安全性」查看是否可以选择「仍要打开」。

安装这个版本后，从「设置 → 软件更新」检查新版。
